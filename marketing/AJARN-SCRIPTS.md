# สคริปต์ให้อาจารย์ปรินนี่โพสต์เอง

> เขียนเป็น **ภาษาพูด** สำหรับอาจารย์พูดเองหน้ากล้อง/พิมพ์เอง
> ไม่ใช่ภาษาโฆษณา เพราะจุดขายคือ "คนจริงที่รู้จริง" ไม่ใช่แบรนด์ที่พูดเก่ง
>
> **กติกาที่ต้องรักษาทุกโพสต์**
> - ห้ามบอกว่า "แม่น 100%" หรือรับประกันผลลัพธ์
> - ห้ามขายด้วยความกลัว (ไม่ดูดวงแล้วจะซวย / ต้องรีบแก้)
> - พูดเรื่องดวงให้เป็นเครื่องมือ "เข้าใจจังหวะ" ไม่ใช่ "ทำนายโชคชะตาแบบตายตัว"

---

## กลุ่ม A — คลิปสั้น 30–45 วินาที (TikTok / Reels / Shorts)

### A1. "ทำไมดวงราศีเดียวกันถึงไม่เหมือนกัน" — คลิปเปิดตัวที่ดีที่สุด

```
[ฮุก 0-5 วิ · พูดตรงกล้อง]
"คนราศีเดียวกัน ดวงไม่เหมือนกันนะคะ
 แล้วทำไมเราถึงอ่านดวงราศีเหมือนกันหมด"

[อธิบาย 5-25 วิ]
"เพราะดวงราศี ใช้แค่ตำแหน่งพระอาทิตย์อย่างเดียว
 แต่ตอนคุณเกิด บนฟ้ามีดาวอีกเป็นสิบดวง
 แล้วแต่ละดวงอยู่คนละตำแหน่งกับของคนอื่น

 คนเกิดวันเดียวกัน แต่คนละเวลา ลัคนาก็คนละราศีแล้วค่ะ
 ห่างกันสองชั่วโมง ดวงก็เปลี่ยนเรื่องแล้ว"

[ปิด 25-40 วิ]
"เพราะงั้นเวลาอาจารย์ดูให้ใคร
 อาจารย์ขอวันเกิด เวลาเกิด แล้วก็สถานที่เกิด
 ไม่ใช่แค่ราศี เพราะมันคนละความละเอียดกันเลยค่ะ"

[CTA] "ใครอยากรู้ว่าดวงตัวเองจริง ๆ เป็นยังไง ทักมาได้นะคะ"
```

### A2. "ดาวเสาร์ไม่ได้แปลว่าซวย" — แก้ความเข้าใจผิด (คนชอบมาก)

```
[ฮุก] "พอบอกว่าดาวเสาร์เข้า ทุกคนหน้าเสียเลย"

[เนื้อ]
"ดาวเสาร์ไม่ได้แปลว่าซวยนะคะ
 ดาวเสาร์แปลว่า 'ถึงเวลาที่ต้องรับผิดชอบ'

 มันจะมาตอนที่เราปล่อยอะไรค้างไว้นาน ๆ
 งานที่ไม่ยอมตัดสินใจ ความสัมพันธ์ที่ไม่ยอมคุยกัน
 เสาร์ไม่ได้ทำให้พัง เสาร์แค่ทำให้เรื่องที่ค้างมันโผล่ขึ้นมาให้เห็น

 คนที่ผ่านช่วงเสาร์ได้ดี คือคนที่ยอมจัดการ ไม่ใช่คนที่หนี"

[ปิด] "เพราะงั้นถ้าช่วงนี้รู้สึกหนัก ๆ ลองถามตัวเองว่า
       มีอะไรที่เราเลื่อนมานานแล้วหรือเปล่าคะ"
```

### A3. "อาจารย์ไม่เคยบอกใครว่าจะเกิดอะไร"

```
[ฮุก] "มีคนถามอาจารย์ว่า ปีนี้จะรวยไหม"

[เนื้อ]
"อาจารย์ตอบคำถามแบบนั้นไม่ได้ค่ะ
 แต่อาจารย์บอกได้ว่า ปีนี้ดวงคุณเปิดทางไหนไว้ให้

 บางปีดวงเปิดเรื่องงาน แต่คนดันไปทุ่มเรื่องความรัก
 พอปีผ่านไปก็บอกว่าดวงไม่ดี ทั้งที่ประตูมันเปิดอยู่คนละบาน

 ดวงไม่ได้บอกว่าจะเกิดอะไร
 ดวงบอกว่าช่วงนี้ 'ลมพัดไปทางไหน' แล้วเราค่อยเลือกว่าจะกางใบเรือยังไง"

[ปิด] "อาจารย์ดูให้ได้แค่ทิศลมค่ะ ส่วนเรือคุณเป็นคนถือหางเสือเอง"
```

### A4. "ทำไมอาจารย์เขียนเองทุกบท"

```
[ฮุก] "มีคนถามว่าทำไมไม่ให้ AI เขียนคำทำนาย จะได้เร็ว"

[เนื้อ]
"อาจารย์เขียนไปแล้วห้าพันกว่าบทค่ะ นั่งเขียนเองทีละบท

 เพราะเวลาคนเปิดอ่านดวงตอนเช้า
 บางคนเขากำลังเครียดเรื่องงาน บางคนเพิ่งเลิกกับแฟน
 คำพูดที่เขาจะได้อ่านมันมีน้ำหนักกับใจเขาจริง ๆ

 อาจารย์เลยไม่กล้าปล่อยให้อะไรที่ไม่เข้าใจคนมาเขียนแทน"

[ปิด] "ดวงมันเรื่องละเอียดอ่อนค่ะ อาจารย์เลยขอเขียนเอง"
```

## กลุ่ม B — โพสต์ยาว (IG / Facebook)

### B1. โพสต์ประจำสัปดาห์: "ดาวประจำสัปดาห์"

```
[ดาว] สัปดาห์นี้ดาวอังคารเข้าเรื่องการสื่อสาร

ช่วงนี้หลายคนจะรู้สึกว่าพูดอะไรออกไปแล้วมันแรงกว่าที่ตั้งใจ
หรือไม่ก็เจอคนพูดใส่แบบไม่ทันตั้งตัว

ดาวอังคารทำให้เราอยากพูดให้จบ อยากเคลียร์ให้ไว
ซึ่งดีตรงที่กล้าพูดสิ่งที่ค้างไว้ แต่ต้องระวังเรื่องจังหวะ

สัปดาห์นี้ถ้าจะคุยเรื่องหนัก ๆ กับใคร
ลองเลื่อนไปคุยตอนที่ทั้งสองฝ่ายพักผ่อนพอแล้วนะคะ
เรื่องเดียวกัน พูดคนละเวลา ผลลัพธ์คนละเรื่องเลย

— อาจารย์ปรินนี่
```

> ⚠️ ก่อนโพสต์ทุกครั้ง เช็กดาวจริงของสัปดาห์นั้นก่อน อย่าใช้ตัวอย่างนี้ตรง ๆ

### B2. โพสต์ตอบคำถามที่คนถามบ่อย

```
คำถามที่อาจารย์ได้รับบ่อยที่สุดคือ "เนื้อคู่อยู่ไหน"

อาจารย์มักจะถามกลับว่า ตอนนี้คุณกำลังมองหาอะไรอยู่คะ
เพราะดวงคู่มันบอกได้ว่าเราเข้ากับคนแบบไหน
แต่มันไม่ได้ชี้ตัวคนให้

สิ่งที่อาจารย์ดูให้ได้จริง ๆ คือ
· ช่วงไหนของชีวิตที่ดวงคุณเปิดเรื่องความสัมพันธ์
· คุณมักจะไปเจอคนแบบไหนซ้ำ ๆ แล้วทำไม
· จุดที่คุณมักพลาดในความสัมพันธ์คืออะไร

ข้อสามนี่แหละที่เปลี่ยนชีวิตคนได้จริงกว่าการรู้ว่าเนื้อคู่หน้าตายังไง

— อาจารย์ปรินนี่
```

### B3. โพสต์แนะนำแคมเปญ (ใช้หลัง 15 ก.ย.)

```
ทุกวันที่ 15 อาจารย์จะเปิดดวงของสมาชิกทุกคนดู

แล้วดูว่าเดือนนั้นดาวเดินมาทำมุมกับดวงเกิดของใครแรงที่สุด
คนนั้นอาจารย์จะขอเวลาคุยด้วยเป็นการส่วนตัวหนึ่งชั่วโมง ไม่มีค่าใช้จ่าย

ไม่ใช่การจับรางวัลนะคะ ไม่ต้องลุ้น ไม่ต้องลงทะเบียน
เพราะมันคำนวณจากดวงล้วน ๆ

เหตุผลที่อาจารย์ทำแบบนี้ คือช่วงที่ดาวเดินแรงกับดวงใครสักคน
มันมักจะเป็นช่วงที่ชีวิตเขากำลังเปลี่ยนผ่านพอดี
อาจารย์เลยอยากคุยกับคนที่กำลังอยู่ตรงจุดนั้นค่ะ

— อาจารย์ปรินนี่
```

## กลุ่ม C — สตอรี่สั้น (โพสต์ได้ทุกวัน ใช้เวลา 1 นาที)

1. `"เช้านี้ดวงจันทร์อยู่ราศี___ ใครรู้สึกอ่อนไหวเป็นพิเศษ ไม่ได้คิดไปเองนะคะ"`
2. `"วันนี้มีคนทักมาถามเรื่องเดียวกันสามคน — เรื่อง___ ช่วงนี้ดาวมันเข้าเรื่องนี้จริง ๆ ค่ะ"`
3. `"คำถามที่ตอบยากที่สุดวันนี้: ___"` (ไม่เปิดเผยตัวคนถาม)
4. `"เพิ่งเขียนคำทำนายบทที่ ___ เสร็จ วันนี้เขียนเรื่อง___"`
5. โพลล์: `"ช่วงนี้เรื่องไหนหนักสุด — งาน / เงิน / ความรัก / สุขภาพ"` แล้ววันถัดไปตอบเรื่องที่คนโหวตมากสุด

## เคล็ดถ่ายคลิปให้ดูน่าเชื่อถือ (ไม่ต้องใช้อุปกรณ์)

- **พูดกับคนเดียว** ไม่ใช่พูดกับ "ผู้ชม" — นึกภาพลูกค้าคนหนึ่งที่เพิ่งทักมา
- **อย่าท่องสคริปต์** อ่านทำความเข้าใจแล้วพูดด้วยคำของตัวเอง ติดขัดบ้างได้ ดูจริงกว่า
- **ฮุก 3 วินาทีแรกสำคัญที่สุด** เริ่มด้วยประโยคที่คนเถียงในใจ เช่น "ดาวเสาร์ไม่ได้แปลว่าซวย"
- **หันหน้าเข้าหาแสง** นั่งหันหน้าเข้าหน้าต่าง ไม่ต้องมีไฟ
- **คลิปเดียวหนึ่งเรื่อง** อย่ายัดสามเรื่องในคลิปเดียว

## ยังขาดข้อมูลจาก Bon/อาจารย์ (ทำให้คอนเทนต์แรงขึ้นอีกมาก)

ผมเขียนสคริปต์ชุดนี้โดย**ไม่แตะเรื่องส่วนตัวของอาจารย์เลย** เพราะเดาไม่ได้
ถ้าได้ 3 อย่างนี้มา ผมเขียนสคริปต์ที่ทรงพลังกว่านี้อีกชุดได้:

1. **เรื่องที่ทำให้อาจารย์เริ่มดูดวง** — คนจำเรื่องเล่าได้ ไม่จำสถิติ
2. **เคสที่อาจารย์จำได้ไม่ลืม** (ไม่ต้องบอกชื่อ) — คอนเทนต์ที่คนแชร์ต่อมากที่สุดคือเรื่องแบบนี้
3. **เรื่องที่อาจารย์เคยดูผิด** แล้วได้เรียนรู้อะไร — ฟังดูเสี่ยง แต่ทำให้คนเชื่อมากที่สุด
   เพราะคนที่กล้าบอกว่าตัวเองเคยพลาด คือคนที่ไม่ได้พยายามขายของ
