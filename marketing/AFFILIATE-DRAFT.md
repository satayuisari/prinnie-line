## 1. แผนหาพาร์ทเนอร์ 3 ระยะ

**ระยะ 1 — ล็อตทดลอง 5 คน (2 สัปดาห์แรก)**
เป้าหมายไม่ใช่ยอดขาย แต่คือ**พิสูจน์ว่าท่อทำงาน**: มีคลิก → มีสมัคร → มีจ่ายจริง → ค่าคอมเข้า ledger ถูกต้อง
เลือกคนที่คุยง่าย ตอบเร็ว ไม่ต้องผู้ติดตามเยอะ (5k–30k พอ) สายดูดวง/ไลฟ์สไตล์/ความรัก

**ระยะ 2 — ขยายเป็น 15–20 คน (เดือนที่ 2)**
ดูจากข้อมูลจริงว่าใครพาลูกค้าจ่ายจริงได้ แล้วทุ่มครีเอทีฟให้คนกลุ่มนั้น
คนที่คลิกเยอะแต่ไม่มีคนจ่าย = คนดูไม่ตรงกลุ่ม ไม่ต้องเสียเวลาต่อ

**ระยะ 3 — คัดเหลือคนที่ทำเงินได้จริง**
ดู CAC ต่อคน (แดชบอร์ดคำนวณให้แล้ว) ใครเกิน 100 บาท/ลูกค้า = ไม่คุ้ม scale

## 2. เกณฑ์คัดพาร์ทเนอร์ (ใส่ในหน้า Recruitment ได้เลย)

ให้คะแนนข้อละ 0–5 รวม 30:
- **ตรงกลุ่ม** — คนดูเป็นคนที่เชื่อเรื่องดวงจริงไหม
- **engagement** — คอมเมนต์/ยอดวิว สมส่วนกับผู้ติดตามไหม (ซื้อยอดหรือเปล่า)
- **คอนเทนต์** — ทำเองสม่ำเสมอ ไม่ใช่รีโพสต์
- **ความน่าเชื่อถือ** — คนดูเชื่อคำแนะนำของเขาไหม
- **ชวนกดเป็น** — เคยขายของ/พาคนคลิกลิงก์ได้จริงไหม
- **brand safety** — ไม่มีดราม่า ไม่มีเนื้อหาเสี่ยง

**ตัดทิ้งทันทีถ้า:** เคยขายของผิดกฎหมาย · เนื้อหาข่มขู่ให้กลัวเพื่อขายดวง · ผู้ติดตามปลอมชัดเจน

## 3. ข้อความทาบทาม (ส่งทาง DM)

```
สวัสดีครับ เห็นคอนเทนต์ของคุณแล้วคิดว่ากลุ่มผู้ติดตามค่อนข้างตรงกับ Prinnie
ซึ่งเป็นบริการดูดวงผ่าน LINE

ตอนนี้เราเปิด Affiliate Partner รุ่นแรกครับ

มีลิงก์เฉพาะให้แต่ละ Partner ระบบนับตั้งแต่คนคลิก → สมัคร → ชำระเงินจริง

ค่าตอบแทน 50 บาท / ลูกค้าใหม่ที่ชำระเงินจริงครั้งแรก

ทางเรามี Link / Creative / Caption ให้พร้อม
ทดลองทำได้โดยไม่มีค่าใช้จ่ายครับ
```

**ถ้าเขาถามว่า "ได้เท่าไหร่ต่อเดือน"** — อย่าโม้ตัวเลข ตอบตามจริง:
> ขึ้นกับว่าคนดูของคุณตรงกลุ่มแค่ไหนครับ ตอนนี้เราเพิ่งเปิดโปรแกรม
> ยังไม่มีตัวเลขเฉลี่ยให้อ้างอิง ลองทำดูก่อนได้ ไม่มีข้อผูกมัด
> แล้วผมส่งรายงานให้ดูทุกสัปดาห์ว่าลิงก์คุณทำงานยังไง

## 4. คอนเทนต์ให้พาร์ทเนอร์เอาไปโพสต์

**แคปชั่นสั้น**
```
ลองดูดวงกับ Prinnie ดู แม่นแบบไม่ต้องทักไปถามใคร
เช็กดวงรายวัน ไพ่ทาโรต์ ดวงคู่ ครบใน LINE
[ลิงก์เฉพาะของคุณ]
```

**แคปชั่นยาว**
```
ช่วงนี้มีคนถามเรื่องดูดวงเยอะมาก เลยขอแนะนำ Prinnie

เป็นบริการดูดวงผ่าน LINE ที่ผูกดวงกำเนิดจริงจากวันเวลาเกิด
- ดวงรายวันส่งให้ทุกเช้า
- ไพ่ทาโรต์ + พื้นดวง + ดวงคู่
- ไม่ต้องรอคิว ไม่ต้องทักไปถามใคร

ใครอยากลอง กดลิงก์นี้ได้เลย
[ลิงก์เฉพาะของคุณ]
```

**CTA ให้เลือกใช้**
- กดลิงก์ในไบโอ เช็กดวงวันนี้ได้เลย
- ทักไปลองก่อนได้ ไม่ต้องจ่ายตอนแรก
- ใครเกิดเดือนนี้ ลองเช็กดูว่าดวงเปลี่ยนยังไง
- ลิงก์อยู่ในคอมเมนต์แรกนะ

**มุมคอนเทนต์ที่ทำงานกับสายดูดวง**
1. "ดวง 12 ราศีที่อ่านฟรีทั่วไป ไม่ใช่ดวงคุณ" — ชูจุดต่างเรื่องดวงกำเนิดรายบุคคล
2. รีวิวจากประสบการณ์ตัวเอง — ให้เขาลองใช้จริงก่อนโพสต์ (สำคัญมาก)
3. เปิดไพ่ประจำสัปดาห์แล้วชวนคนไปเปิดเอง (ของฟรี = ประตูเข้า)
4. ดวงคู่ — คอนเทนต์คู่รักมี engagement สูงสุด

## 5. ⚠️ กฎที่พาร์ทเนอร์ห้ามทำ (ใส่ในชุดส่งมอบ)

- ห้ามอ้างว่า "แม่น 100%" หรือรับประกันผลลัพธ์
- ห้ามใช้ความกลัวขาย (เช่น ไม่ดูดวงแล้วจะซวย)
- ห้ามแอบอ้างเป็นอาจารย์ปรินนี่ หรือพูดแทนอาจารย์
- ห้ามสัญญาสิ่งที่เราไม่ได้ให้ (เช่น คืนเงิน/ดูดวงฟรีกับอาจารย์)
