## 4. คลิปหลัก 1 ตัว (5-8 นาที) — โครงสคริปต์

**หัวข้อคลิป:** ทำไมคนราศีเดียวกัน ดวงถึงไม่เหมือนกัน

- **Hook (0-15 วิ):** "ถ้าคุณกับเพื่อนราศีเดียวกัน แต่ชีวิตคนละเรื่องเลย
  คลิปนี้จะบอกว่าทำไม แล้วดวงจริง ๆ ของคุณดูจากตรงไหน"
- **เนื้อ (15 วิ - 6 นาที):** อธิบาย 3 ชั้น — อาทิตย์ (ตัวตน) / จันทร์ (อารมณ์ข้างใน) /
  ลัคนา (ภาพที่คนอื่นเห็น) ยกตัวอย่างคนดังราศีเดียวกันแต่ลัคนาต่าง → นิสัยคนละแบบ
- **สาธิต (6-7 นาที):** เปิดหน้าจอ กรอกวันเกิดตัวอย่างใน LINE → โชว์ว่าได้พื้นดวงจริงทันที
- **CTA (ปิดท้าย):** "ของคุณเป็นแบบไหน แอดไลน์ในลิงก์ใต้คลิป กรอกวันเกิดรับฟรีเลย
  ไม่มีค่าใช้จ่าย" + ปักหมุดคอมเมนต์ข้อ 2

**pinned + description ใช้ลิงก์ `?s=yt` เสมอ**
