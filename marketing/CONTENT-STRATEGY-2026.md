## 0. TL;DR (อ่านอันเดียวพอ)

- ตลาด "มูเตลู" ไทย = **฿10,000–15,000 ล้าน**, คนไทย **88% เชื่อ**, **52 ล้านคน** มีพฤติกรรมมูฯ
- คนอยากได้ 3 อย่าง: **เงิน 44% · โชค 17% · สุขภาพ/ความรัก** — และจะมูฯ **หนักขึ้นตอนเศรษฐกิจไม่แน่นอน**
- **ปุ่มกดที่ทำให้คนจ่าย = ความ "จริงใจ/ของแท้" (authenticity) ไม่ใช่เหตุผล** — มูเตลูปลอม ๆ ทำลายความเชื่อใจ *เร็วกว่า* โฆษณาธรรมดา → ของเรามี **เครื่องคำนวณดวงจริง** = ได้เปรียบโครงสร้างนี้เต็ม ๆ
- LINE OA ไทย = **read rate 80–90%**, broadcast ได้ 2–3 ครั้ง/สัปดาห์ไม่โดนบล็อก → **ดวงรายวัน = ช่องที่แข็งแรงที่สุดเชิงโครงสร้าง**
- คู่แข่งทั้งหมด (LINE TODAY, Thairath, Sanook, MyHora, Duanglive) = **ดวงตามราศี/วันเกิดแบบทั่วไป** ไม่มีใครทำ natal chart ส่วนบุคคลจริงบน LINE → **นี่คือ white space ของเรา**
- **3 คอนเซ็ปต์** (ตรงกับ 3 ฟีเจอร์ที่ live แล้ว + 3 ความต้องการหลักของคนไทย):
  - **A · "ดวงที่เป็นของคุณคนเดียว"** (ดวงส่วนตัว/natal) — **68%**
  - **B · "ทักทุกเช้า"** (ดวงรายวัน/พิธีกรรมยามเช้า) — **82%** ⭐ แนะนำเป็นแกนหลัก
  - **C · "ผูกดวงคู่"** (synastry/ไวรัล-คู่รัก) — **74%** ⭐ แนะนำเป็นหัวหอกหาคนใหม่
- **สูตรชนะ = B เป็นกระดูกสันหลัง (retention+รายได้) × C เป็นหัวหอกไวรัล (acquisition) × A เป็นหลักฐาน "ของจริง" (trust/wow)** — ไม่ต้องเลือกอันเดียวตลอดไป แต่ **launch ให้ C นำ → ดูดคนเข้า → ส่งมอบ B → พิสูจน์ด้วย A**

## 1. ตลาด & กลุ่มเป้าหมาย (เจาะลึก)

### 1.1 ขนาดตลาด & พลวัต
| ตัวเลข | ค่า | นัยต่อเรา |
|---|---|---|
| มูเตลูอีโคโนมี | ฿10–15 พันล้าน | ตลาดใหญ่พอที่ niche เล็ก ๆ ก็เลี้ยงธุรกิจได้ |
| คนไทยเชื่อมูฯ | 88% | แทบไม่ต้อง "สร้างความเชื่อ" — แค่ชนะใจให้เลือกเรา |
| คนมีพฤติกรรมมูฯ | 52 ล้านคน | TAM มหาศาล |
| อยากได้ | เงิน 44% · โชค 17% · สุขภาพ 12% · ความรัก | **คอนเทนต์ควรพูดเรื่องเงิน/งาน/รักเป็นหลัก** |
| ราคาดูดวงออนไลน์ | เริ่ม ~฿100/ครั้ง | 399/เดือนของเรา = คุ้มถ้าสื่อสารว่า "ส่งทุกวัน" |
| ผู้เล่นหน้าใหม่ | อายุ 20–30, social-native, ไลฟ์ขายดวง | คู่แข่งคือครีเอเตอร์เดี่ยว ไม่ใช่ระบบอัตโนมัติ |

### 1.2 จิตวิทยาผู้บริโภค (จากงานวิจัย "Muketing" 2025)
แรงขับที่ทำให้คนไทยจ่ายเงินให้สิ่งศักดิ์สิทธิ์/ดวง — **ไม่ใช่เหตุผล แต่คืออารมณ์**:
1. **ความมั่นคงทางใจ (emotional security)** — "อยากได้ที่ยึดเหนี่ยวตอนชีวิตไม่แน่นอน" ← แรงขับเบอร์ 1
2. **ความรู้สึกมีอำนาจควบคุมชีวิต (agency)** — ดวงให้ "ทางออก/สิ่งที่ทำได้" คืนความรู้สึกคุมเกม
3. **ความต่อเนื่องทางวัฒนธรรม** — สีมงคล/เลขมงคล/สัญลักษณ์ = ตัวแทนความมั่งคั่ง
4. **พิธีกรรม/ความหมาย** — เปลี่ยนเรื่องธรรมดาให้ศักดิ์สิทธิ์

> **กฎทอง (the trust paradox):** ความ "จริงใจ" คือคันโยก conversion เบอร์ 1.
> มูเตลูที่ดู *ฉวยโอกาส/ปลอม* → คนตราหน้าว่า "หลอกลวง" และเลิกเชื่อทั้งแบรนด์ เร็วกว่าโฆษณาทั่วไป.
> **แอ็กชันของเรา:** โชว์ "กลไกจริง" (คำนวณจากตำแหน่งดาวจริง ณ วินาทีเกิด), ห้ามโม้เกินจริง, ห้ามขู่ให้กลัวแล้วขายของ.

### 1.3 เซกเมนต์ (ใครคือคนจ่าย)
| เจน | อายุ | อยากได้ | มุมที่ใช้ |
|---|---|---|---|
| **Gen Y (millennial)** ⭐ จ่ายดีสุด | ~27–42 | ผลลัพธ์เรื่อง **งาน เงิน ความรัก** | ดวงรายวันที่ "ใช้ตัดสินใจได้" + ผูกดวงคู่ |
| **Gen Z** | 18–26 | สุนทรียะ/แชร์ได้/ทลายกรอบ | คอนเทนต์ไวรัล ผูกดวงคู่ wallpaper ดวง |
| **Gen X** (หญิงเป็นหลัก) | 43–58 | สุขภาพ ความมั่นคง | โทนอุ่น ให้กำลังใจ ดวงรายวัน |

- **เพศ:** ดูดวง/community เอียงไป **ผู้หญิง** ชัด (ผู้หญิงผูกพันฟีเจอร์ชุมชน/แชร์เรื่องราวมากกว่า) → ครีเอทีฟควรมี female lead
- **อายุ 19–25** ชอบ interactive/พิธีกรรม · **30+** เน้น "ของแท้/น่าเชื่อถือ" → คุมโทนให้ **พรีเมียมจริงใจ ไม่กุ๊กกิ๊กเกินไป**

### 1.4 ภูมิทัศน์คู่แข่ง (ช่องว่างของเรา)
ทุกเจ้าหลัก = **ดวงรวมตามราศี/วันเกิด** (one-size-fits-12):
- LINE TODAY horoscope, Thairath, Sanook, MyHora, Duanglive, หมอดูไลฟ์รายคน
- **ไม่มีใคร** ส่ง "ดวงส่วนตัวจาก natal chart จริง + ดาวจรเฉพาะคุณ ทุกเช้า อัตโนมัติ บน LINE"
- หมอดูไลฟ์เก่งเรื่อง "คน/ความจริงใจ" แต่ **สเกลไม่ได้** (1 ต่อ 1) — เราสเกลได้ด้วยระบบ แต่ต้อง "ใส่ความเป็นคน" กลับเข้าไปในแบรนด์ (Prinnie = หน้าเป็นคน)

## 2. สามคอนเซ็ปต์ครีเอทีฟ (พร้อม % โอกาสสำเร็จ)

> "%" = ประเมินโอกาสที่คอนเซ็ปต์นั้นจะทำเป้าหมาย (ดึงคนแอด + เปลี่ยนเป็นคนจ่าย + รักษาไว้) ได้จริง
> อิงจุดแข็งสินค้า + พฤติกรรมตลาด + โครงสร้างช่องทาง — เป็นการประเมิน ไม่ใช่ตัวเลขรับประกัน

### 🅐 "ดวงที่เป็นของคุณคนเดียว" — Personalization-as-Magic — **68%**
**บิ๊กไอเดีย:** ราศีเดียวกัน ดวงไม่เหมือนกัน. โชว์ความว้าวของ natal chart ส่วนตัว = แผนที่ดาว ณ วินาทีคุณเกิด
**Key visual:** `concept-personal.png` (ผู้หญิงยืนหน้าจักรราศีทองเรืองแสง)
**Hook หลัก:** "ราศีเดียวกัน ทำไมดวงไม่เหมือนกัน?" / "นี่คือแผนที่ดาวของคุณคนเดียวในโลก"
**เครื่องจักรคอนเทนต์:**
- Educational Shorts: "ลัคนาคืออะไร", "อาทิตย์ vs จันทร์ vs ลัคนา", "ทำไมแอปดวงทั่วไปไม่แม่นกับคุณ"
- Reveal: คนกรอกวันเกิด → เห็นพื้นดวงตัวเอง (wow moment) → แคปแชร์
- Authority: Prinnie อธิบายศาสตร์ → สร้างความน่าเชื่อถือ (ตรงกับ "authenticity = conversion")
**โฆษณา/โปสเตอร์:** "แผนที่ดาวของคุณ ณ วินาทีที่คุณลืมตาดูโลก — ฟรี" + ภาพจักรราศีส่วนตัว
- **ข้อดี:** ใช้ moat ของสินค้าตรง ๆ (engine จริง), ต่างจากคู่แข่งชัดสุด, สร้าง trust ลึก
- **ข้อเสีย/ความเสี่ยง:** "ความเป็นส่วนตัว" เป็นนามธรรม สื่อใน 3 วินาทียาก, ต้องให้ความรู้ก่อน (funnel ยาวขึ้น), เพดานไวรัลต่ำกว่า C
- **เหมาะเป็น:** ชั้น "พิสูจน์ของจริง/authority" ที่เสริม B และ C — ไม่ใช่หัวหอกไวรัลเดี่ยว

### 🅑 "ทักทุกเช้า" — Daily Morning Ritual — **82%** ⭐ แกนหลัก
**บิ๊กไอเดีย:** ทุกเช้ามีคน(ดวงดาว)ที่รู้จักคุณ ส่งคำทักทาย+คำแนะนำเฉพาะคุณ. ขายที่ "ความมั่นคงทางใจ" (แรงขับเบอร์ 1 ของตลาด)
**Key visual:** `concept-daily.png` (มือถือเรืองแสงบนเตียง เหนือทะเลเมฆยามรุ่งอรุณ)
**Hook หลัก:** "เริ่มเช้านี้ด้วยดวงที่รู้จักคุณจริง ๆ" / "ทุกเช้า เปิดมาเจอคำแนะนำเฉพาะคุณ"
**เครื่องจักรคอนเทนต์:**
- Daily snippet: ตัวอย่างดวงเช้าสั้น ๆ (โทนอุ่น ให้กำลังใจ) — สร้างนิสัย
- **สีมงคล/เลขมงคล/เวลามงคลประจำวัน** (ตรงจริตมูเตลู "timing alignment" + เงิน/โชค)
- Relatable: "ดวงเช้านี้บอกว่า..." แล้วคนรู้สึก "ตรงจัง"
- ใช้พลังโครงสร้าง LINE: read rate 80–90% → ดวงเช้าเปิดอ่านเกือบทุกคน
**โฆษณา/โปสเตอร์:** ภาพมือถือยามเช้า + "ดวงส่วนตัวของคุณ รออยู่ทุกเช้า บน LINE"
- **ข้อดี:** ตรงแรงขับลึกสุดของตลาด (reassurance+ritual), ใช้จุดแข็ง LINE เต็ม, โมเดล retention พิสูจน์แล้วระดับโลก (Co-Star: DAU 30–40% จากนิสัยเช็กดวงทุกวัน), ครอบคลุมทั้ง Gen Y/X หญิงที่จ่ายดี, **ตรงกับตัวสินค้าที่สุด** (เราคือ "บริการรายวัน")
- **ข้อเสีย/ความเสี่ยง:** เพดานไวรัลต่ำ (เน้น retention > acquisition) → ต้องมี C/A ป้อนคนเข้ามาก่อน, ความต่างจาก "ดวงรายวันทั่วไป" ต้องตอกย้ำคำว่า "เฉพาะคุณ" ตลอด
- **ทำไมสูงสุด:** โอกาสสำเร็จเชิงรายได้ที่ "ยั่งยืน" สูงสุด เพราะมันคือสันหลังของ subscription จริง ๆ

### 🅒 "ผูกดวงคู่" — Couple / Synastry (Viral) — **74%** ⭐ หัวหอกหาคนใหม่
**บิ๊กไอเดีย:** ลองผูกดวงกับคนที่คุณคิดถึง. ไวรัลในตัวเพราะต้อง 2 คน + ความรัก = ความต้องการ top + ผู้หญิงชอบแชร์
**Key visual:** `concept-couple.png` (สองใบหน้ามีกลุ่มดาว เชื่อมด้วยเส้นแสงทอง)
**Hook หลัก:** "เราเข้ากันกี่ %?" / "ผูกดวงกับคนที่คุณแอบคิดถึง — ฟรี"
**เครื่องจักรคอนเทนต์:**
- Couple reveal: ใส่ 2 วันเกิด → คะแนน % + มุมดวงเด่น → แชร์/แท็กกัน (UGC engine)
- ดวงคู่ราศี (เช่น "มังกร+กรกฎ เข้ากันไหม"), ดวงคู่คนดัง/ไอดอล (ไวรัลง่าย)
- เพื่อน/ครอบครัวก็ผูกได้ (ขยายจากคู่รัก)
**โฆษณา/โปสเตอร์:** สองพอร์เทรต + เส้นกลุ่มดาวเชื่อม + "เราถูกลิขิตให้เจอกันไหม? เช็กฟรี"
- **ข้อดี:** **ความเร็วในการหาคนใหม่ + virality สูงสุด** (กลไกแท็ก/แชร์ในตัว), ความรัก = high-intent, มี UGC engine, **โมเดลจ่าย 149 ครั้งเดียวพร้อมแล้ว** (มี upsell 399), ตรง female-community insight
- **ข้อเสีย/ความเสี่ยง:** แคบกว่า B, ความแปลกใหม่อาจจางถ้าไม่เติม format ใหม่, พึ่งกลไกแชร์ทางสังคม (ถ้าคนไม่แชร์ = แผ่ว), อารมณ์คนเรื่องความรักอ่อนไหว — ผลต้องดูจริงใจ ไม่ตีหัวเข้าบ้าน
- **เหมาะเป็น:** ปากกรวยที่ดูดคนเข้า OA เร็วที่สุด แล้วส่งต่อให้ B รักษาไว้

### ตารางเทียบ
| | A · ดวงส่วนตัว | B · ทักทุกเช้า ⭐ | C · ผูกดวงคู่ ⭐ |
|---|---|---|---|
| % โอกาสสำเร็จ | **68%** | **82%** | **74%** |
| จุดเด่น | moat/ต่างชัด/trust | retention+รายได้ยั่งยืน | ไวรัล/หาคนเร็ว |
| บทบาทในกรวย | พิสูจน์ของจริง | **กระดูกสันหลัง** | **หัวหอก acquisition** |
| ฟีเจอร์ที่ใช้ | natal (ฟรี hook) | ดวงรายวัน (paid) | synastry (149) |
| เพดานไวรัล | กลาง | ต่ำ | **สูง** |
| เพดานรายได้ | กลาง | **สูง** | กลาง-สูง |
| ความเสี่ยง | funnel ยาว | acquisition ต่ำ | novelty/พึ่งแชร์ |

## 3. คำแนะนำ — เล่นแบบบูรณาการ (ไม่ใช่เลือกอันเดียว)

**สูตร: C นำ → B รับ → A ค้ำ**
```
[C ผูกดวงคู่]  ไวรัล/แชร์/แท็ก  ──►  ดึงคนแอด LINE ใหม่ (acquisition)
        │
        ▼
[A พื้นดวงส่วนตัว]  กรอกวันเกิด → เห็นดวงตัวเอง (wow + พิสูจน์ของจริง = trust)
        │
        ▼
[B ทักทุกเช้า]  ดวงรายวันเฉพาะคุณ → นิสัย → จ่าย 399/เดือน (retention + รายได้)
        │
        ▼
บอกต่อ/ชวนแฟนผูกดวงคู่  ──►  วนกลับ C
```
- **ถ้าต้องเลือก "หนึ่งธีมนำ" สำหรับ launch แคมเปญแรก → เลือก C (ผูกดวงคู่)** เพราะหาคนเข้าเร็วสุด ต้นทุนไวรัลต่ำสุด แล้วระบบ B/A ที่ทำเสร็จแล้วจะเก็บเกี่ยวเอง
- **ถ้าโฟกัสรายได้/ความยั่งยืนเป็นหลัก → ให้ B เป็นแกน** แล้วใช้ C/A เป็นตัวป้อน

## 4. แผนอาร์ตเวิร์ก & แบรนด์ (สิ่งที่ Bon กังวล)

### 4.1 Visual system (ใช้ร่วมกันทุกชิ้น = แบรนด์จำได้)

## 5. KPI & การตัดสินใจ
- **Acquisition:** แอด LINE ใหม่/วัน + มาจากคอนเซ็ปต์ไหน (A/B/C)
- **Activation:** % กรอกวันเกิดจบใน LIFF (wow moment สำเร็จ)
- **Retention:** % เปิดอ่านดวงรายวันซ้ำ (เป้าหมายแบบ Co-Star: DAU 30–40%)
- **Viral:** จำนวนเคสผูกดวงคู่ + แชร์/แท็ก (ตัวชี้ C)
- **Revenue:** conversion เป็น 399/เดือน + 149 ครั้งเดียว, MRR
- **กฎ broadcast:** ≤2–3 ครั้ง/สัปดาห์, block rate <10% (ถ้าเกิน = ลดความถี่ทันที)
