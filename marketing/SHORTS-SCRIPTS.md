> โครงทุกคลิป: **Hook (0–3s) → เนื้อ → Twist+CTA** · ปิดท้ายชวนแอด LINE @prinnie333 รับพื้นดวงฟรี
> กฎเหล็ก: ห้ามพูดราคา · ขาย "ของฟรีที่เป็นส่วนตัว" (ดู [[prinnie-line-positioning]])

## 🎬 คลิป 1 — Educational (Concept A · พื้นดวงส่วนตัว)
**ชื่อ/ฮุก:** "ราศีเดียวกัน ทำไมดวงไม่เหมือนกัน?"
**เป้า:** สร้าง authority + ตอกย้ำ personalization → ดึงคนกรอกวันเกิด

| เวลา | ภาพ | เสียง/ข้อความบนจอ |
|---|---|---|
| 0–3s | โคลสอัพหน้าคนสองคน (split) ใต้คำว่า "ราศีสิงห์ทั้งคู่" | **"ราศีเดียวกันเป๊ะ… แต่ชีวิตคนละเรื่องเลย ทำไม?"** |
| 3–10s | กราฟิกวงจักรราศีหมุน + จุดดาวอาทิตย์/จันทร์/ลัคนาวิ่ง | "เพราะ 'ราศี' บอกแค่ตำแหน่งพระอาทิตย์ตอนคุณเกิด — แค่ 1 ดวงจากหลายสิบดวง" |
| 10–20s | โชว์ natal chart ส่วนตัว (poster-personal-9x16 เป็น bg) | "ดวงจริงของคุณ = อาทิตย์ + จันทร์ + ลัคนา + ดาวอีกเพียบ คำนวณจาก วัน-เวลา-สถานที่เกิดคุณคนเดียว" |
| 20–30s | ปกแบรนด์ + ปุ่ม LINE เด้ง | **"อยากรู้ว่าจันทร์กับลัคนาคุณอยู่ราศีไหน? แอด LINE @prinnie333 รับพื้นดวงส่วนตัวฟรี"** |

**แคปชั่น:** ราศีเดียวกันดวงไม่เหมือนกัน เพราะดวงจริงคำนวณจากวันเกิดคุณคนเดียว 🌙 รับพื้นดวงฟรีที่ LINE @prinnie333
**แฮชแท็ก:** #ดูดวง #ลัคนา #ดวงส่วนตัว #โหราศาสตร์ #ราศี #prinnie333

## 🎬 คลิป 2 — Couple Hook (Concept C · ผูกดวงคู่) ⭐ ตัวไวรัล
**ชื่อ/ฮุก:** "ใส่วันเกิด 2 คน รู้เลยเข้ากันกี่ %"
**เป้า:** ไวรัล/แท็กกัน → ดูดคนใหม่ (มี share card รออยู่ในระบบแล้ว)

| เวลา | ภาพ | เสียง/ข้อความบนจอ |
|---|---|---|
| 0–3s | การ์ดผลเด้งเลข % ใหญ่ (เหมือน couple card ในแอป) | **"เราเข้ากันกี่ %? ลองกับคนที่คุณแอบคิดถึงสิ 👀"** |
| 3–12s | สาธิตกรอกวันเกิด 2 คนในมือถือ → กดดู | "ไม่ใช่แค่ 'ราศีไหนเข้ากับราศีไหน' — แต่ผูกดวงจริงของสองคน ดูดาวรักส่งถึงกันแค่ไหน" |
| 12–22s | การ์ดผลโชว์ % + 'ดวงคู่แท้' + จุดเด่น | "ได้คะแนนเข้ากัน + จุดที่เคมีตรงกัน + จุดที่ต้องเข้าใจกัน" |
| 22–32s | ปุ่มแชร์/แท็ก + ปก LINE | **"แท็กเขามาลองเลย 💞 เช็กฟรีที่ LINE @prinnie333"** |

**แคปชั่น:** เราเข้ากันกี่ %? 💞 ผูกดวงคู่จากวันเกิดจริงของสองคน แท็กคนนั้นมาลองเลย → LINE @prinnie333
**แฮชแท็ก:** #ผูกดวงคู่ #ดวงความรัก #ดวงคู่ #เนื้อคู่ #ความรัก #prinnie333
**หมายเหตุ:** ปิดคลิปด้วยการโชว์ "ปุ่มแชร์การ์ด" จริง — ย้ำว่าแชร์ผลเข้าแชทเพื่อนได้

## 🎬 คลิป 3 — Relatable (Concept B · ดวงรายวัน)
**ชื่อ/ฮุก:** "ดวงรายวันที่คนทั้งราศีได้เหมือนกัน… มันใช่ดวงคุณจริงเหรอ?"
**เป้า:** ชูจุดต่างของดวงรายวัน "ส่วนตัว" → retention/สมัคร

| เวลา | ภาพ | เสียง/ข้อความบนจอ |
|---|---|---|
| 0–3s | สก์รีนดวงรายวันเว็บทั่วไป "ราศีสิงห์วันนี้…" | **"ดวงรายวันแบบนี้… คนเป็นล้านได้ข้อความเดียวกันเป๊ะ"** |
| 3–12s | เปรียบเทียบ: มือถือเด้งดวงเช้า "ส่วนตัว" (poster-daily-9x16) | "แต่ดวงดาวขยับทุกวัน และมันทำมุมกับ 'ดวงเกิดของคุณ' ไม่ซ้ำใคร" |
| 12–22s | คลิปข้อความดวงเช้าเฉพาะบุคคล (mock) | "ดวงรายวันส่วนตัว = อิงดาวจรที่วิ่งสัมพันธ์กับวันเกิดคุณเอง ส่งให้ทุกเช้า" |
| 22–32s | ปกแบรนด์ + LINE | **"เริ่มจากของฟรี — แอด LINE @prinnie333 รับพื้นดวงส่วนตัวก่อนเลย"** |

**แคปชั่น:** ดวงรายวันที่เป็น 'ของคุณคนเดียว' ต่างกับดวงราศีรวมยังไง ☀️ เริ่มฟรีที่ LINE @prinnie333
**แฮชแท็ก:** #ดวงรายวัน #ดวงวันนี้ #ดวงส่วนตัว #ดูดวง #prinnie333
